# Crypto Investment Analysis Skill

A professional, institutional-grade 4-layer cryptocurrency analysis skill (Macro, Fundamental, On-Chain, Technical).

**Agent-Neutral:** This skill works universally across AI agents including Hermes, Claude Code, Cursor, Codex, OpenCode, and Goose.

## Installation via skills.sh

```bash
npx skills add thatssoheil/crypto-investment-analysis --agent hermes-agent claude-code cursor codex opencode goose -g -y
```
